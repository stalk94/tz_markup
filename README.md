## Установка и запуск

1. Клонировать репозиторий:
```bash
   git clone https://github.com/stalk94/tz_markup
   cd <папка_проекта>
```
2. Установить зависимости:
```bash
   npm install
```
2. Запустить проект в режиме разработки:
```bash
   npm run dev
```
